# 🎬 MovieTalk - Hollywood Movie Recommendation System

Discover 1,000 iconic Hollywood movies with real TMDB poster artwork, embedded YouTube trailers, interactive 3D parallax detail showcases, box office metrics, and exclusive editorial reviews presented by **Balaji Shankar** and **Sai Kumar**.

---

## 🌟 Key Features

- **1,000 Movie Catalog**: Search by title, director, year, or genre.
- **Real TMDB Posters & YouTube Trailers**: High-resolution poster artwork and 1-click video trailer modal playback.
- **Editorial Film Reviews**: In-depth analysis, quotes, and score breakdowns by lead analysts Balaji Shankar & Sai Kumar.
- **Full-Screen Flagship Showcase**: Apple TV+ / HBO Max style 100vh hero stage with 3D tilt poster card, 4K HDR Atmos badges, and key scene timeline beats.
- **Theater Lighting Mode**: Dim page environment with a single click to focus on the cinema stage.
- **Community Reviews**: Interactive 5-star ratings, user review submissions, and helpful thumbs-up counters with `localStorage` persistence.

---

## 🚀 Quick Start

1. Clone or download this repository.
2. Open `index.html` in any modern web browser or start a local HTTP server:
   ```bash
   python -m http.server 8080
   ```
3. Navigate to `http://localhost:8080` to experience MovieTalk!
